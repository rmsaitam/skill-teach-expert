# Adaptation and language

## Language

The `Language` field in `GOALS.md` is authoritative. Every explanation, question, feedback, transcript, footer, and reply to the user uses that language. The HTML `lang` attribute and the `lang` field of the `teach:lesson-html` marker must match `Language`.

If the user writes in another language but the study directory already has `Language`, continue in the registered language and ask before changing it. An explicit change creates a new goal recorded in `GOALS.md`.

Technical terms may stay in their original language when the source uses them, but must be explained in the user's language on first occurrence.

## Level

- Beginner: one idea per lesson, analogies, no assumed prior vocabulary, three recall questions.
- Intermediate: connection to concepts already seen, short verified example, application question.
- Advanced: exact version, documented limitations, edge case, and two independent sources for sensitive claims.

## Time

`Minutes per Session` limits the lesson. Respect the limit by shortening explanations and examples, never by removing citations, the quiz, or source verification. If the subject needs more time, split it into two lessons.

## Non-code subjects

The same flow applies to languages, history, science, finance, or any other subject. The primary source changes: official grammars and dictionaries for languages, laws and public documents for law, academic papers for science, official reports for finance. The rule stays the same: no verified source, no claim.
